Cookie Policy

No tracking cookies in the current build.

This page explains the cookie and tracking status of the current Target Media website code.

Last updated: 9 September 2026

1. Current status

Cookies set by site codeNone
AnalyticsNone
Advertising trackersNone

The current repository does not load Google Analytics, Meta Pixel, advertising networks, heatmaps or equivalent tracking technology. It also does not load external fonts, video players, map widgets, chat tools or review widgets that automatically contact third parties.

2. Why there is no consent banner

Under Dutch cookie rules, explicit consent is required for tracking cookies and some privacy-sensitive analytical technologies. Functional cookies and low-impact analytics can fall within an exception, although visitors still need to be informed.

Because this current site code sets no cookies and includes no optional tracking, there is nothing for the visitor to accept or reject. We therefore do not show a performative “Accept cookies” banner.

If optional analytics, marketing cookies, pixels or similar technologies are added later, they must not load before any legally required consent has been obtained. The visitor must be able to refuse as easily as accept and withdraw consent later.

3. Local browser functions are not used for tracking

The pilot-brief generator runs in the browser and does not use cookies, localStorage or sessionStorage to save the values entered. The clipboard function runs only when the visitor presses the copy button.

4. Hosting and network logs

A hosting or network provider may process technical request logs such as IP addresses for delivery, abuse prevention or security. Server logs are not the same thing as cookies placed by the website. The production hosting arrangement must still be covered by the Privacy Policy and re-audited if the hosting stack changes.

5. Future changes

Adding any of the following requires a privacy/cookie review before deployment: analytics platforms, A/B testing, advertising pixels, embedded videos, maps, chat widgets, social-media embeds, fingerprinting, conversion tracking or third-party session replay.

If the site begins using cookies, this page should list each cookie or category, purpose, provider, retention period and whether consent is required.

6. Dutch guidance

Dutch guidance states that tracking cookies and some analytical cookies require prior consent; consent must be an active choice, refusal must be available, pre-ticked boxes are not valid consent, and withdrawing consent must be as easy as giving it.

Official references: Business.gov.nl — cookies · ACM — cookies · Autoriteit Persoonsgegevens.
